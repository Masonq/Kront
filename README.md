# Kront — мастера в Белграде

Маркетплейс услуг мастеров для Сербии. Языки: сербский (латиница и кириллица), русский.

- `web/` — Next.js 15 (страницы отдаются сервером для SEO), сайдбар, каталог, страницы «услуга × район», профиль мастера, заявка.
- `api/` — FastAPI + PostgreSQL: каталог, районы, мастера, поиск «своими словами», заявки, данные для sitemap.
- `docker-compose.yml` — db + api + web, сайт на порту 8095.

## Деплой
```
bash deploy.sh
```
Отчёт о деплое — `reports/deploy.log`.

8 демо-мастеров (`demo=true`, закрыты от индексации). Фото — CC0 (stocksnap.io).
